✳ AI Studio — Claude AI
Claude AI से चैट करें या Playwright ब्राउज़र के ज़रिए किसी वेबसाइट पर काम करवाने का अनुरोध करें।

केवल उसी वेबसाइट पर काम करें जिसे खोलने की अनुमति आपके पास है। पासवर्ड या OTP चैट में भेजने से पहले सावधानी बरतें।

यह सिस्टम कैसे काम करता है?

1. यूज़र इस GitHub Pages वेबसाइट पर निर्देश लिखता है。
2. JavaScript निर्देश को Render के backend API तक भेजता है。
3. सामान्य चैट के लिए Render, Claude API से जवाब लेता है。
4. वेबसाइट ऑटोमेशन के लिए Render पर Python और Playwright ब्राउज़र खोलकर पेज की जानकारी लेते हैं और ज़रूरी कार्रवाई करते हैं。
5. Claude अगले कदम का निर्णय लेने में मदद करता है。
6. जवाब Render से वापस इस चैट में आता है।
